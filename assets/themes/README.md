# 可选主题素材

默认玻璃皮肤不显示角色。奶龙使用浅金、奶蛙使用奶油色玻璃面板；右上人物与收起按钮分列，奶龙采用较短的上半身视窗，不拉伸原素材。图片随安装文件打包，切换时不请求素材网站，不发送页面信息。

- 奶龙：透明形象 PNG，来自 [奶龙官方 IP 形象页](https://www.nailoong.com/business/ipIncubation/)，[原图](https://www.nailoong.com/_ipx/q_85/img/business/nl_base_3d.png)。
- 奶蛙：用户提供的黄色、绿色眼睛的奶蛙形象，经内置 imagegen 去除白底，使用透明 PNG 显示完整轮廓；没有相框和矩形底色。1.4.1 使用内置 imagegen 重新清理人物外缘，去除贴纸描边、背景残留；两款主题关闭人物外部投影，避免灰色光圈。

图片与角色权利属于各自权利人，项目不主张其权利，也不将其纳入代码许可。用户提供或公开可见均不等于获得再许可；再分发时需遵循权利人的许可要求。

manifest.json 记录来源与 SHA256；构建器逐项校验后嵌入安装文件，公开检查仅排除这一段可核验的素材编码。
