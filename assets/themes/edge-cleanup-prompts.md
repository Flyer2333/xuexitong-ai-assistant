# 透明人物外缘清理（1.4.1）

使用内置 imagegen 编辑已有素材，输出真实透明 PNG。只保留两款已有角色，不改姿势、表情或角色身份。安装文件内置最终图像；生成图保留透明通道，按面板需求缩小，不拉伸。

奶龙提示：去除整圈白色贴纸描边、灰色外缘和角色之外的阴影；保留黄色3D角色、绿眼睛、表情、手势与腹部；真实轮廓仅保留自然抗锯齿，不添加背景或新描边。

奶蛙提示：清理真实轮廓外的灰边、杂色、散点和外部阴影；保留思考姿势、眼睛、手部、材质、颜色；真实透明背景，不添加白描边或深色底。

最终文件和 SHA256 见 manifest.json。面板同时关闭这两款人物的 CSS drop-shadow，避免重新产生灰色光圈。
