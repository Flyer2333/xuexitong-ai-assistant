# 安装与日常使用

## 一、准备 API

1. 选一个提供 API 的厂商，进入其开发者控制台创建属于自己的 Key。
2. 核对账号实际开通的模型 ID、接口区域、余额、图片能力。模型名称不要从聊天网页标题猜。
3. 浏览器能访问该 API 的网络才可调用；安装脚本不会改变代理或地区资格。
4. 使用视觉模型时保持“发送题目截图”勾选；纯文字模型取消。特殊字体加密题目应使用视觉模型。

## 二、安装油猴脚本

1. 安装官方 Tampermonkey 扩展。浏览器要求时，在扩展详情允许用户脚本/开启开发者模式，具体名称依浏览器版本。
2. 打开项目 `dist/xuexitong-ai-assistant.user.js` 的 Raw 页面。确认脚本名“超星学习通自动化脚本（支持接入各种主流AI模型api）”、版本 1.0.1，然后安装。
3. 未弹安装页时，先下载文件，打开油猴管理面板 → 添加新脚本 → 删除默认示例 → 粘贴文件全文 → Ctrl+S。ZIP 源码包不是油猴备份包，不能直接当油猴 ZIP 导入。
4. 进入课程页，停用其他控制同一页面的学习通脚本，刷新后检查右下角面板。公开版与本机版命名和命名空间不同，不会自动覆盖旧版，必须主动停用旧版。

## 三、填写设置

1. 展开“AI 接口设置”。
2. 选择服务商。预设只填协议和地址，不附带 Key，也不硬编码可能过期的模型 ID。
3. Base URL 填厂商文档对应的基础路径，例如 OpenAI 为 `https://api.openai.com/v1`。不要加 `/chat/completions` 或 `/responses`。
4. 填完整模型 ID、API Key；按模型能力选择是否发送截图。纯图片选项或题干配图必须启用截图，并选择支持图片输入的模型；DeepSeek、小米等预设默认文字模式时需按实际视觉模型能力手动开启。
5. 初次保留 JSON 模式未选、推理强度默认。厂商明确支持时再开启；“xhigh”并非所有模型都支持。
6. 输出上限默认 8192 token；这是上限，不是每次固定消耗。推理模型可能把预算用于思考，返回空内容时可增加上限或降低推理强度。
7. 保存后 Key 输入框自动清空，仅显示“已保存”；同一服务商、协议和地址下留空可保留已有 Key。更换任一目标必须重新输入 Key，避免把旧密钥发送给其他主机。
8. 点“测试 AI”：会产生一条可能收费的短请求。测试只验证文字连接和 JSON 返回，不证明该模型支持图片或能正确答题。

## 四、开始与停止

- 点“开始自动”。有视频则播放，有检测则进入检测；视频内弹题答后还会点击继续学习。
- 可以先在章节检测使用“仅看答案”，展开截图预览检查题干与特殊字体显示，确认后再开始自动。
- 停止会取消模型请求并阻止后续填写；已经发出的请求可能仍被服务商计费。
- 夜间暂停按北京时间而非设备系统时区。页面关闭、电脑休眠、浏览器冻结后不会按点执行恢复。
- 新版本需从 Raw/Release 重新安装、刷新页面。未配置自动更新 URL，避免把尚不存在的个人仓库地址写进脚本。

## 五、可选本地 Codex

不使用 API 时才需要这一节。电脑需有 Node.js 和可用的 Codex CLI，并按其官方方式完成登录。

1. 下载源码，打开终端进入项目目录。
2. 运行 `node src/bridge.mjs`，不要关闭该服务终端。
3. 首次会生成 `src/local/bridge-token.txt`。在你自己的电脑打开，复制其中连接码；不要提交到 GitHub，也不要发给他人。
4. 面板选择“本地 Codex”，Base URL 保持 `http://127.0.0.1:18763`，把连接码填入 Key 栏并保存。
5. 点“测试 AI”先检查本地服务健康，再开始。健康检查不会调用模型；首次真实答题才能验证 CLI 登录与模型调用。

如果命令不存在，设置环境变量 `XXT_CODEX_BIN` 为你自己的 CLI 原生可执行文件路径，再启动。Windows 下不要填无法直接执行的 `.cmd` 包装器路径。服务不再内置作者磁盘路径。

可选 `XXT_CODEX_MODEL` 与 `XXT_CODEX_REASONING` 决定本地 CLI 的模型和推理强度；不填则沿用 CLI 自身默认行为。API 设置里的模型/推理选项不改变 Codex 服务配置。修改环境变量后重启该服务。服务仅监听回环地址，默认 18763；调整 `XXT_CODEX_PORT` 后也要改面板地址。

## 六、常见问题

| 现象 | 排查 |
| --- | --- |
| 没有面板 | 检查扩展启用、域名匹配、用户脚本权限；刷新，停用旧脚本 |
| 401 | 核对该厂商 Key；Codex 模式核对本机连接码 |
| 403 | 账号模型权限、地区资格、网络拦截；不要反复重试 |
| 404 | Base URL/模型 ID/区域或接入点不一致 |
| 400 | 换成模型支持的协议；关 JSON/推理参数；文字模型不要传图 |
| 429 | 服务商限流或余额不足；脚本不自动无限重试 |
| 返回非 JSON | URL 可能是网页而非 API，或模型没有按格式输出 |
| 空响应/输出未完成 | 推理占用预算、被内容策略拦截或模型不兼容 |
| 当前题目包含图片 | 当前关闭了截图；启用截图并选择视觉模型，保存后重新开始 |
| 题目图片读取失败 | 图片损坏、超时、跨域未授权或来源不能读取；检查预览，不会继续随机提交 |
| 连接失败 | 检查网络、油猴对目标域名的授权和 HTTPS 地址 |
| 页面已答对仍停住 | 确认最新版、没有手动停止/处于夜间；看面板具体原因；点击继续只允许一次，平台未响应会暂停 |
| 文档没有完成标记 | 预览可能跨域、任务规则不同；60 秒停留不等于保证任务点完成 |

反馈问题时只附页面结构或截图、面板提示、协议/服务商及模型名。不要附 Key、连接码、Cookie、完整课程链接或油猴存储导出。
