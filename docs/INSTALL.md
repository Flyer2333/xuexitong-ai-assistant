# 安装与日常使用

第一次使用请依次完成安装、配置和连接测试。想先了解自动流程，可阅读 [完整功能说明](FEATURES.md)。

## 安装前准备

1. 选择 AI 服务商，在其开发者控制台创建自己的 API Key。
2. 从控制台复制可用的模型 ID，核对接口区域、余额，以及模型是否支持图片输入。聊天网页里的模型名称未必能用于 API。
3. 确认电脑可以访问接口。脚本不会修改代理设置，也不会改变账号的地区或模型权限。
4. 使用视觉模型时勾选“发送题目截图”，使用纯文字模型时取消。图片题和特殊字体题需要视觉模型。

## 安装脚本

1. 安装官方 Tampermonkey（油猴）扩展。若浏览器提示需要额外权限，在扩展详情中允许用户脚本运行；部分版本需要开启开发者模式。
2. 打开仓库中的 `dist/xuexitong-ai-assistant.user.js`，点击 **Raw**。安装页应显示“超星学习通自动化脚本（支持接入各种主流AI模型api）”，本教程对应版本 1.0.6。
3. 没有出现安装页时，下载脚本文件，然后打开油猴管理面板 → 添加新脚本 → 删除默认示例 → 粘贴文件全部代码 → Ctrl+S。源码 ZIP 不能通过油猴的备份导入功能安装。
4. 停用其他控制同一页面的学习通脚本，再打开或刷新课程页。右下角出现“学习助手”面板即表示脚本已加载。标题下方“外观”可切换默认、奶龙、奶蛙三种皮肤，选择会保存。不同名称或命名空间的脚本可能同时运行，安装新脚本不会自动停用它们。

## 配置 AI

1. 展开“AI 接口设置”。
2. 选择服务商，面板会填入预设协议和地址。模型 ID 和 Key 需要自己填写。
3. Base URL 填厂商文档对应的基础路径，例如 OpenAI 为 `https://api.openai.com/v1`。不要加 `/chat/completions` 或 `/responses`。
4. 填写完整模型 ID、API Key。题干配图或纯图片选项需要开启截图，并选择支持图片输入的模型。DeepSeek、小米等预设默认关闭截图；改用视觉模型后请手动开启。
5. 初次使用先不勾选 JSON 模式，推理强度保持默认。确认接口支持后再开启；部分模型不接受“xhigh”。
6. 最大输出默认 8192 token，实际消耗按请求计算。推理过程也可能占用输出预算；若返回空内容，可尝试增加上限或降低推理强度。
7. 点击“保存设置”。Key 输入框会清空，只显示已保存提示。同一服务商、协议和地址下，留空保存会保留原 Key；更换其中任一项后，需要重新输入 Key。
8. 点击“测试 AI”。API 模式会发送一条短请求，可能收费。测试成功表示文字请求和 JSON 返回正常，图片能力和答案正确性仍需另行确认。

## 开始、停止和更新

- 点击“开始自动”，脚本会按当前页面处理视频、文献或检测。视频弹题答对后恢复当前视频，同页多个视频逐个处理，之后处理文献、专题和检测；本章所有学习步骤完成才进入下一章。未知或未完成任务会暂停，不强行跳过。
- 面板的“静音播放”默认开启，取消后尝试有声播放，选择会保存。若浏览器阻止有声自动播放，请手动播放或重新勾选静音后开始。
- 章节重做若重复失败答案，最多增加两次 AI 复核，可能增加用量；仍重复时尝试未提交组合。它不代表平台已确认答案正确。
- 可以先在章节检测使用“仅看答案”，展开截图预览检查题干与特殊字体显示，确认后再开始自动。
- 停止会取消模型请求并阻止后续填写；已经发出的请求可能仍被服务商计费。
- 夜间暂停按北京时间而非设备系统时区。页面关闭、电脑休眠、浏览器冻结后不会按点执行恢复。
- 更新时，从仓库 Raw 页面或已发布的 Release 下载新版 `.user.js` 并安装，然后刷新课程页。当前未设置专用自动更新地址，请手动检查版本。

## 使用专题阅读

课程显示“去阅读”时，开始自动后会在新标签打开专题目录。请让阅读标签保持前台并获得焦点，每项累计 90 秒；切走会暂停计时。进度会保存，刷新或重新开始后可接续。读完后脚本关闭本次打开的阅读标签，回原课程先找本章检测；没有自动切回时请手动切回。

专题页也需要启用同一个脚本。如果阅读页没有接入、目录或正文识别失败，原课程面板会提示原因。目录变黄和本地计时结束不代表平台已记录完成。

## 可选：连接电脑上的 Codex

使用 API 的用户可以跳过这一节。连接 Codex 需要电脑已安装 Node.js 和可用的 Codex CLI，并完成 CLI 登录。

1. 下载并解压源码，在终端中进入项目目录。
2. 运行 `node src/bridge.mjs`，不要关闭该服务终端。
3. 首次启动会生成 `src/local/bridge-token.txt`。打开该文件，将连接码复制到脚本设置中。连接码用于验证本机访问，不要上传或分享。
4. 面板选择“本地 Codex”，Base URL 保持 `http://127.0.0.1:18763`，把连接码填入 Key 栏并保存。
5. 点击“测试 AI”，确认本地服务可以连接后再开始。此测试不会调用模型，不能单独确认 CLI 登录和模型调用是否正常。

如果服务找不到 Codex，设置环境变量 `XXT_CODEX_BIN`，填入电脑上 Codex CLI 的原生可执行文件路径，再重新启动服务。Windows 下不要填写无法直接执行的 `.cmd` 包装器路径。

可通过 `XXT_CODEX_MODEL` 和 `XXT_CODEX_REASONING` 指定 CLI 的模型与推理强度，留空则使用 CLI 默认设置。面板中的 API 模型和推理选项不改变 Codex 服务配置。修改环境变量后需重启服务。服务只监听本机回环地址，默认端口 18763；修改 `XXT_CODEX_PORT` 后，请同步修改面板地址。

## 常见问题

| 现象 | 排查 |
| --- | --- |
| 没有面板 | 检查扩展启用、域名匹配、用户脚本权限；刷新，停用旧脚本 |
| 401 | 核对该厂商 Key；Codex 模式核对本机连接码 |
| 403 | 账号模型权限、地区资格、网络拦截；不要反复重试 |
| 404 | Base URL/模型 ID/区域或接入点不一致 |
| 400 | 换成模型支持的协议；关 JSON/推理参数；文字模型不要传图 |
| 429 | 服务商限流或余额不足；脚本不自动无限重试 |
| 返回非 JSON | URL 可能是网页而非 API，或模型没有按格式输出 |
| 空响应/输出未完成 | 推理占用预算、被内容策略拦截或模型不兼容 |
| 当前题目包含图片 | 当前关闭了截图；启用截图并选择视觉模型，保存后重新开始 |
| 字体加载或截图生成超时 | 刷新后检查题目和图片是否正常加载，再重新开始；本次不会提交 |
| 题目图片读取失败 | 图片损坏、超时、跨域未授权或来源不能读取；检查预览，不会继续随机提交 |
| 连接失败 | 检查网络、油猴对目标域名的授权和 HTTPS 地址 |
| 专题计时不增长 | 保持阅读标签在前台、有焦点，确认没有手动暂停或进入夜间休息；检查原课程仍在运行 |
| 文档滚动无法确认 | 检查内部阅读器是否加载、跨域页面是否启用脚本；按提示手动处理未完成任务点 |
| 页面已答对仍停住 | 确认最新版、没有手动停止/处于夜间；看面板具体原因；点击继续只允许一次，平台未响应会暂停 |
| 文档没有完成标记 | 预览可能跨域、任务规则不同；60 秒停留不等于保证任务点完成 |

反馈时请提供面板提示、服务商、协议和模型名，并按需附上脱敏截图或页面结构。不要上传 Key、连接码、Cookie、完整课程链接或油猴存储导出。
