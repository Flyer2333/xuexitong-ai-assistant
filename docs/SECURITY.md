# 数据、密钥与权限

## 数据流

```text
课程页面 -> 油猴脚本 -> 使用者配置的 AI API -> 本地校验答案 -> 页面操作
```

发送内容包括题干、选项、题目标识、启用时的题目截图、必要的最近几轮平台反馈。没有作者运营的服务器，不上传 Cookie、账号密码或整份课程目录，不自动收集题库。模型收到的网页内容只作数据，提示词要求不执行其中指令。

API Key 放在油猴 `GM_setValue('xxt-ai-config', ...)` 中，不在课程 localStorage/DOM 状态中持久保存，不随源码发布。输入时仍在客户端内存/表单中，油猴存储不是加密保险箱；浏览器扩展、调试工具或已控制浏览器的程序仍可能访问。应使用自己能撤销、限制额度的 Key，不在不可信脚本中填写高权限凭据。

Key 输入框保存后清空，修改 Base URL、服务商或协议不能自动沿用旧 Key。配置改变会停止当前自动任务。日志和 API HTTP 错误不显示原始厂商响应，以免服务商把密钥反射进错误信息。

## 权限

- `GM_xmlhttpRequest`、`@connect *`：访问使用者设置的 API。远程地址强制 HTTPS，HTTP 只允许本机回环地址；URL 禁止携带用户名、密码、查询参数。使用匿名请求、不带浏览器 Cookie，配置拒绝跳转，并校验最终响应主机。
- `GM_getValue/GM_setValue`：用户的 AI 配置、倍速、休息偏好及答题状态。
- `GM_openInTab`：兼容可选的新标签文献预览，只关闭脚本自己打开的标签句柄。
- `unsafeWindow`：与课程播放器、frame 协调；不读取登录凭据。
- 没有使用远程 `@require`：库固定打入安装文件，并附许可证。

Tampermonkey 不同版本对重定向控制支持可能不同，优先使用新版扩展和厂商规范 HTTPS 地址。自填网关能收到你的 Key、题目与截图，使用者须确认该网关可信。

图片题额外准备题干/选项中的图片：先尝试已加载图片或浏览器正常读取；浏览器回退仅允许对 HTTPS chaoxing.com 及子域发 GM 图片请求。图片请求不带 API Key/本地连接码，GM 回退匿名，并检查 MIME、体积与解码；同源浏览器读取可能使用平台本来的图片访问权限。处理好的 PNG 仅替换截图克隆，向 AI 发送截图和来源散列标识，不发送原图 URL。单题最多 40 张图、准备预算 30 秒；失败时停止。

## 费用与停止

API 调用按使用者的服务商账单计费。连接测试也会调用模型；Codex 模式的健康检查例外，只访问本机服务。停止请求不保证服务商撤销已计费的请求，脚本不会自动购买额度、添加付费订阅或轮换账号。

## 发布及反馈

Git 已忽略 `src/local/`、日志、环境配置、token 文件和 artifacts。`.gitignore` 不会清理曾经提交过的秘密；如果泄露应先撤销 Key，再清理历史。

报告漏洞请先移除敏感信息。不要在 Issue/公开 PR 粘贴真实 Key、Cookie、连接码、课程私有 URL 或个人身份信息。检查器只能找已知泄露模式，不能替代人工审阅。
