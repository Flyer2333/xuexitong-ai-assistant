# 数据与隐私说明

## 数据流

```text
课程页面 -> 油猴脚本 -> 使用者配置的 AI API -> 本地校验答案 -> 页面操作
```

AI 请求会携带题干、选项、题目标识，以及必要的最近几轮平台反馈。开启截图后，还会发送题目截图。项目没有作者运营的中转服务器，不上传 Cookie、账号密码或整份课程目录，也不自动收集题库。提示词要求模型将网页内容作为题目数据，不执行其中的指令。

API Key 通过油猴 `GM_setValue('xxt-ai-config', ...)` 保存在脚本管理器中，不写入课程页面的 localStorage 或 DOM 持久状态，也不随源码提供。

输入密钥时，它仍会出现在浏览器内存和表单中。油猴存储并非加密保险箱，浏览器扩展、调试工具或已控制浏览器的程序仍可能访问。建议使用可撤销、可限制额度的 Key，不要在不可信脚本中填写高权限凭据。

保存后 Key 输入框会清空。更换 Base URL、服务商或协议时，需要重新输入 Key，并会停止当前自动任务。为避免服务商响应意外带出密钥，日志和 API HTTP 错误提示不会展示原始响应内容。

## 脚本需要哪些权限

- `GM_xmlhttpRequest`、`@connect *`：访问使用者设置的 API。远程地址强制 HTTPS，HTTP 只允许本机回环地址；URL 禁止携带用户名、密码、查询参数。使用匿名请求、不带浏览器 Cookie，配置拒绝跳转，并校验最终响应主机。
- `GM_getValue/GM_setValue`：用户的 AI 配置、皮肤（`xxt-ui-skin`）、倍速、静音、休息偏好及答题状态（包括失败尝试的题目快照、答案与得分）；也保存专题目标地址、目录进度、已完成项、当前累计时长和随机任务关联。
- `GM_openInTab`：打开文献预览或专题阅读标签，只关闭脚本自己持有的标签句柄。专题页通过脚本存储接续目录与前台计时，不向 AI 发送阅读正文。
- `unsafeWindow`：与课程播放器、frame 协调；不读取登录凭据。
- 没有使用远程 `@require`：库固定打入安装文件，并附许可证。

建议使用新版 Tampermonkey 和服务商提供的 HTTPS 地址；不同扩展版本对重定向控制的支持可能不同。自行填写的网关可以收到 Key、题目和截图，使用前请确认其可信。

### 题目图片如何读取

脚本优先使用已加载的图片或浏览器正常读取。浏览器无法直接读取时，只允许对 HTTPS 的 chaoxing.com 及其子域尝试 GM 图片请求。该请求匿名发送，不附带 API Key 或本地连接码，并检查 MIME 类型、文件大小和能否解码；同源浏览器读取可能使用平台原有的图片访问权限。

处理后的 PNG 用于截图副本，AI 收到截图和图片来源的散列标识，不收到原图 URL。每题最多准备 40 张图片，准备时间预算为 30 秒，失败时停止。

专题阅读页只在可见且获得焦点时累计有效停留，不伪造可见性、用户活动或平台时长请求。文档跨域滚动只向已识别的学习通阅读器发送滚动协调消息，不附带 API 密钥或连接码。

## 费用与停止

API 费用按所选服务商的账单计算，“测试 AI”也会调用模型。章节重做中若 AI 重复失败组合，最多额外调用两次进行复核，可能增加用量。Codex 模式的连接测试只访问本机服务，不调用模型。停止脚本只能取消本地等待，不能保证服务商撤销已接收或已计费的请求。脚本不会购买额度、添加付费订阅或轮换账号。

## 分享文件与反馈问题

项目的 `.gitignore` 已排除 `src/local/`、日志、环境配置、token 文件和 artifacts。它不能删除曾经提交过的秘密；若密钥泄露，应先撤销密钥，再清理仓库历史。

提交 Issue 或公开 PR 前，请移除真实 Key、Cookie、连接码、课程私有 URL 和个人身份信息。源码检查只能发现已知的泄露模式，分享文件前仍需人工检查。

## 角色外观

角色图片随脚本打包，切换皮肤不会向图片网站发起请求，也不会调用 AI。默认皮肤不显示角色。素材记录见 [主题素材说明](../assets/themes/README.md)。
