# 💝 支持作者

如果这个脚本帮你省下了一些时间，欢迎随意打赏，支持后续维护和改进。金额随意，感谢你的支持。

脚本的功能对所有用户开放，打赏不影响使用，也不作为功能或更新的承诺。

## 微信赞赏

打开微信扫一扫下方赞赏码；在手机上浏览时，也可保存图片后在微信中识别。

## 支付宝收款

打开支付宝扫一扫下方收款码；在手机上浏览时，也可保存图片后在支付宝中识别。

<img src="support/alipay.png" alt="作者的支付宝收款码，姓名已遮挡" width="320">

请在支付应用中确认收款人和金额后，自行决定是否付款。项目页面不会自动发起支付，也不收集支付账户、账单或打赏金额。
