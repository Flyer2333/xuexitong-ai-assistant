# 1.3.0 界面边界检查

开发预览：tests/ui-preview.html。使用本地静态服务器打开，底部可切换 Demo data / Worst case / Empty / One / 30 profiles；发布脚本不包含开关。数据均为模拟接口，没有真实密钥。

| 字段 | 来源与限制 | 检查输入 | 呈现决定 |
| --- | --- | --- | --- |
| 模型 ID | 用户/目录，协议校验后使用；列表不截断 | 长部署路径、中文、emoji、o3 | 完整换行、overflow-wrap:anywhere |
| Base URL 主机 | 用户填写，必须为有效 URL | 多层研究机构长域名 | 换行，不把操作按钮挤出 |
| 密钥 | 用户填写，本地存储，最多 30 组接口 | 缺密钥、短密钥、普通密钥 | 缺失提示；列表仅显示掩码 |
| 日期和状态 | 本地存储 | 最近使用为空、尚未测试 | 显示“尚未成功调用”，不伪造日期 |
| 接口列表 | 最多 30 组 | 空、1、30组 | 可滚动、用途按钮始终可达 |
| 状态与错误 | 当前运行和服务商状态码 | 长说明、404模型错误、图片识别错误 | 自动换行；结果 dialog 可关闭 |

## 发现与修复

| 程度 | 场景 | 原因 | 修复位置 |
| --- | --- | --- | --- |
| 内容错误 | 角色 SVG 留白露出相邻人物 | sprite 图片没有按单元裁剪 | src/theme.js 的 figure() 加 clipPath |
| 操作易被裁切 | 小视口/放大后长页头占据正文 | 正文只有独立最大高度 | src/glass.css 的 shell/body 用 flex 与 min-height:0 |
| 反馈不足 | 接口用途变化不清楚 | 没有持久选中状态 | aria-pressed、内凹样式和 live feedback |

15 组数据/宽度组合（320、1100、1920px）及等效200%视口通过几何断言；Demo/Worst的320px与放大视口人工查看截图。暗色、减少动态效果已验证；产品未声明 RTL 支持，未宣称完整 RTL 验收。角色图标不压缩，长名称不溢出，空值不显示 undefined；保留完整模型与主机名供核对。

验证只覆盖隔离浏览器与模拟接口，不代表真实账号、付费调用或实课已通过。
