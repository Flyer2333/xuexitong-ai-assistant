### AI 请求与设置

协议测试覆盖 OpenAI Chat Completions、OpenAI Responses、Claude Messages、Gemini generateContent，以及可选 Codex 连接服务的请求格式。测试包括纯文字模式、JSON 与推理参数开关、国内七家服务商预设、小米接口字段差异、URL 和密钥校验，以及无效、不完整或被拦截的模型输出。

模拟网络测试还检查了连接探测、取消请求和错误提示，确认 HTTP 错误不会直接展示可能包含密钥的服务商原始响应。

浏览器中的四种 API 测试均完成了配置、保存和一次答题流程：保存后清空 Key 输入框；没有重新填写 Key 时拒绝更换接口地址；每种协议发送两次模拟请求（连接测试和答题），提交一次并继续学习一次。服务商下拉框中的七家国内独立预设也已检查。

### 视频与图片

视频题测试使用浏览器原生媒体元素和可解码的 WAV，检查答题后恢复当前媒体、媒体结束后进入检测。截图函数调整后，再次运行了 12 项视频弹题测试，继续学习、停止和切章处理均通过。

图片题测试使用真实 html2canvas 生成 PNG，并检查红、绿、蓝、黄像素是否进入截图；两个黄色区域分别用于确认题干图片与图片选项均被截取。AI、课程页面事件和用户脚本网络接口仍使用模拟环境。

答案校验还覆盖了纯文字模式拒绝图片题、图片选项重排后重新匹配，以及更换题干或选项图片后取消旧答案。

## 尚未验证的部分

- **服务商与模型账号：** 未逐家使用真实付费 Key 测试，也没有验证每个账号的模型和图片权限。“测试 AI”只检查文字连接与返回格式，不能证明视觉能力或答案正确。
- **实际课程：** 未在登录后的真实课程中验证题目提交和任务点完成。新页面结构、特殊字体重绘、文献完成规则、视频编码和真实题图可能与模拟环境不同。
- **Codex 环境：** 连接请求格式已测，但不同操作系统、CLI 版本、路径和登录状态尚未逐一验证。脚本不附带固定个人模型、路径或连接码。
- **图片身份判断：** 图片来源信息使用双 32 位散列辅助匹配，不是按图片像素计算的密码学指纹。服务器在相同 URL 下替换图片内容的情况尚未验证。
- **再分发许可：** 上游未发现 LICENSE 文件，许可范围尚待确认，详见 [来源与许可](../NOTICE.md)。

模拟测试通过只能说明上述场景中的程序行为符合预期。实际使用仍需检查面板提示、截图预览和平台完成标记。网站更新后，已有适配可能失效。

## 开发者复现说明

运行方法见 [开发与发布指南](PUBLISH.md)。测试输出保存在 `artifacts/`，不纳入发布源码。测试默认不产生付费 API 用量。

维护浏览器测试时，请保留以下条件，避免把测试页面错误当成产品问题：

- 合成页面明确使用 UTF-8，防止中文按钮被错误解码。
- 选项断言只检查题目区域，避免误读设置区的 checkbox。
- 倍速测试使用仓库当前的 dist 安装文件，输出写入被 Git 忽略的 artifacts。
- 凭据检测须覆盖源码和安装包；检查器自身包含的检测字符串不应被误判为泄露。

仓库提供 GitHub Actions 配置。某次提交是否通过远端检查，请查看仓库 Actions 中对应提交的结果。
