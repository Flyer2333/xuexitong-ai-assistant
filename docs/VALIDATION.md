# 1.0.0 验证记录

日期：2026-10-15。公开候选版从本机版 0.3.11 分离，原本机目录未修改。

## 已确认

- 从明确文件白名单复制页面控制源码、通用 vendor 和许可证。未复制原 local、日志、连接码、个人课程 HTML、截图或角色 PNG；没有修改用户已有运行服务。
- `node --test tests/api.test.mjs`：10 项通过。五种传输（四种 API 及 Codex）请求/鉴权/图像结构/返回解析、纯文字模式、JSON/推理可选参数、七家国内预设和小米字段差异、URL/密钥校验、非法/不完整/拦截输出、模拟网络成功、探测、取消和错误不反射密钥。
- `node tests/public-browser.mjs`：四种 API 的完整 UI 模拟流程通过：填写、保存后清空 Key 输入框、短请求测试、视频弹题选择/提交、正确后一次继续；更换地址而不重新填 Key 被拒绝。每种协议恰好两次模拟请求（探测及答题）、一次提交、一次继续。无角色元素、七家国内独立选项存在。没有使用真实账号或调用付费 API。
- `node tests/verify-video-quiz.mjs`：沿用 12 项原视频弹题浏览器回归，通过纯模拟的可选本机接口，覆盖单选/多选/判断、本页/同源/跨域、反馈重试、连续弹题、停止及切章旧答案取消。原生 HTMLVideoElement 使用可解码 WAV，答后恢复当前视频，媒体结束后再进入检测。
- `node tests/verify-playback-rate.mjs`：新版界面本页/跨域原生媒体的倍速、建议标记、切章/刷新保留、停止和夜间设置保护通过。
- 公开安装脚本源码与构建同步、JavaScript 语法检查和已知泄露模式检查通过；源码 ZIP 的每个条目解压后逐字节核对，白名单打包排除 src/local、日志、浏览器 profile、凭据和测试 artifacts。
- 通用界面由原生 Chrome 渲染，已目视检查；预览为合成演示页，不是登录后的真实课程。发布目录只带面板裁图，未带个人图片。

## 修复过的测试问题

- 第一次秘密检查匹配到检查器自己的检测字符串；去除个人名字硬编码，并只对其他文件执行个人路径/资产模式检查。源码与包仍全部做凭据及同步检查。
- 倍速回归起初仍读取旧构建路径，并使用个人主题预览输出路径；改为公开 dist 和被忽略的 artifacts，不更改产品行为。
- 新的 API UI 夹具缺少 HTML charset，中文提交按钮被浏览器误解码，导致漏识别；为路由加 UTF-8 后消除。之后提交断言误检查了页面设置区的 checkbox，正确限定为题目选项后通过。没有把这两个夹具错误当作平台缺陷或为通过测试放宽提交条件。

## 尚未验证或尚待处理

- 没有对每个国内外服务商使用真实付费 Key 验证，也没有账户级模型/图片权限证据；连接探测只测文字格式，不证明图片能力。官方接口资料见 PROVIDERS.md 的逐项链接。
- 没有操作用户登录后的学习通完成题目提交或任务点，实际网页新结构、特殊字体重绘、真实文档任务规则与视频编码仍需观察。已有页面适配可能随平台更新失效。
- 可选本地 Codex 的请求格式已测，通用 CLI 路径与不同操作系统、CLI 参数版本及登录状态未逐机实测。没有在公开版内置固定个人模型、路径或配对码。
- 上游仓库未见许可证，来源已标注但再分发授权尚未确认；本候选不代替上游授权。
- 没有创建 GitHub 仓库、推送提交或发布 Release。CI 配置已提供，尚未在 GitHub 服务器上跑过。

测试命令与证据写入本地 `artifacts/`，不纳入发布源码。默认测试使用模拟服务商及网站，费用为零，不以模拟通过冒充实际课程或真实 API 验收。
